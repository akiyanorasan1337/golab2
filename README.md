Это простое приложение на Go, которое считает, сколько дней осталось до Нового года; чтобы его собрать, нужен установленный Go 1.22 или новее, потом в папке проекта надо выполнить go build -o newyear.exe ., запустить через newyear.exe, и сервер начнёт работать на порту 8080, пока открыто окно терминала; тесты запускаются командой go test ./..., а у сервиса есть один адрес GET /days, который возвращает JSON вида {"date":"2024-12-31","days":1}, при этом дату можно не указывать — тогда посчитается от сегодняшнего дня, или указать так: http://localhost:8080/days?date=2024-12-31 в формате YYYY-MM-DD, а если дата неправильная, вернётся ошибка с кодом 400.
